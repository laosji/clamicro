提醒

只有 Mac 本地通知这一条，完全不联网。 远程推送已经去掉了——锁屏可达必须经第三方服务器，而这个工具的前提是你人在附近。 离开电脑后不会有任何东西叫你：高风险操作会等到超时被自动拒绝，那一轮任务失败。 这是有意的默认，人不在就不该放行 rm -rf。

macOS 通知需要审批、任务完成、出错时弹通知并响一声

任务完成通知

任务完成时提醒每轮回复结束都会触发，用下面的时长过滤
最短时长短于此的任务不提醒，避免每问一句都响

单位秒。设 0 表示每轮都提醒。

自动通过的操作也提醒不需要你做决定，但让你知道 Claude 刚跑了什么。关掉的话日常操作它既不拦也不说

审批策略

普通操作自动通过倒计时结束就放行，不需要你做任何事。关掉则每条都等你决定
等待时长这段时间内你随时可以在手机上拒绝

单位秒。高风险操作不受这条影响，见下方。

高风险操作等待时长没人决策时等多久，到点拒绝。别设太长——你走开一次，会话就冻在那里

单位秒，10 – 570。上限是硬的：hook 的系统超时是 600 秒，超过就会被当成非阻塞错误放行到普通权限流程，等于这次审批白做。

高风险操作也自动通过 包括 rm -rf、git push --force、密钥文件、写工作目录之外

关闭时高风险操作会一直等你决策（最长 570 秒），超时则拒绝。 开启后，你没看手机时 rm -rf 会自己放行 —— 这正是审批功能要防的事。
