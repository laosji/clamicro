# Clamicro 使用教程

[← 回到 README](../README.zh-CN.md)

---

## 一、装

```bash
npx clamicro install
```

终端里会依次问你三件事：

**1. 要不要改 `~/.claude/settings.json`**

它会先把改动列出来给你看，再问要不要继续。你已有的 hook 配置一条不动，只追加；改之前自动备份。

**2. 要不要信任当前网络**

手机要连上服务，服务就得暴露到局域网。局域网内是明文传输，所以只在你信任的网络上开——家里、自己的热点可以，咖啡厅不行。

换到陌生网络时服务会自动缩回本机，等你再次确认。这是有意的保护，不是故障。

**3. 要不要开机自启**

不需要。`SessionStart` hook 会在你打开 Claude Code 时自动把服务拉起来。只有当你想「没开 Claude Code 时也能用手机翻记录」才需要开。

最后会打印一个二维码。

## 二、第一次：走完一遍才算装好

用手机相机扫那个二维码，浏览器会打开首页。

登录一次就行——口令存成了 cookie，一年有效。以后手机上直接开那个地址。

**建议顺手做两件事：**

**加到主屏幕。** Safari 分享菜单 → 添加到主屏幕。之后它就是一个图标，没有地址栏，观感接近 App。

**跑一次验收。** 「设置」→ 最底下的「发一条测试审批」。这会造一条假的待审批，你在手机上批一次——**批准或拒绝都不会真的执行任何操作**。走完这一遍，说明整条链路是通的。

## 三、日常怎么用

### 场景一：你就在电脑边

什么都不用配。需要授权时：

- Mac 弹通知并响一声
- 终端状态栏出现 `⏳ 1 条待审批`
- 手机网页上也能看到

普通操作（`npm run build` 之类）**10 秒后自动通过**，你根本不用管。只有高风险操作会一直等你。

### 场景二：你离开了电脑，但还在同一 Wi-Fi

需要配 Bark，否则没有任何东西能叫到你。

「设置」→ 手机推送 → 点「还没装？去 App Store」装 Bark → 打开 Bark 复制首页那串 key → 粘回设置页。

配好之后，高风险操作会把手机叫响。点通知直接进审批页。

> 不配 Bark 也能用，只是你必须自己想起来去打开网页。而高危操作在你不知情时会等到超时被拒绝，任务失败。

### 场景三：你不在同一 Wi-Fi

默认用不了，这是设计如此。真需要的话装 Tailscale——服务会自动识别并绑上去，且不受网络信任限制。详见 [README 的安全章节](../README.zh-CN.md)。

## 四、审批页怎么读

这是唯一真正重要的一屏，从上到下：

```
┌──────────────────────────────────┐
│ my-project  …/dev/my-project 8:42│  ← 哪个会话，还剩多久
├──────────────────────────────────┤
│                                  │
│  [Bash] [改动文件] [规则 Bash]   │  ← 工具 + 影响面 + 命中的权限规则
│                                  │
│  清理构建产物并强制推送           │  ← 一句人话，这是主角
│                                  │
│  ⚠️ 高风险操作                    │  ← 只有高危才出现
│  递归/强制删除 · 强推覆盖远端     │
│                                  │
│  ▸ 查看完整命令（3 行）           │  ← 原文默认折叠，短命令直接摊开
│                                  │
│  ← 左滑拒绝 · 高风险，右滑需划得更远 → │
│  ━━━━━━━━━━━━━  8:42 后自动拒绝   │  ← 不操作会怎样
└──────────────────────────────────┘
```

**最该看的是那句人话**，不是命令原文。它来自 Claude Code 自己对这次操作的描述。

**影响面标签**（只读 / 改动文件 / 联网 / 提权）是从命令里提取的。不展开原文也能判断——`ls` 和 `rm -rf /` 长得不一样。

**底部那行倒计时**回答「我不管它会怎样」：

- 绿色「后自动通过」= 普通操作，10 秒后放行
- 灰色「后自动拒绝」= 高风险，等你决定，超时则拒绝

## 五、手势

| 动作 | 结果 |
|---|---|
| 左滑 | 拒绝 |
| 右滑 | 批准 |
| 高风险右滑 | 要划得更远（约屏幕 55%），而且不能"甩" |
| 列表里高风险右滑 | **完全划不动**，必须点进详情页 |

滑到某个位置时图章会「咬合」——放大、反白、震一下。**那一刻就是承诺点**，此时松手就会执行。没到那个状态松手会弹回来。

批准之后有 **3 秒撤销窗口**，全屏倒计时环，点「撤销」就取消。拒绝立即生效，不给撤销——误拒是安全方向，让 Claude 重试一次就行。

## 六、还能做什么

**看时间线** ——「会话」tab 点任意会话，能看到那个会话的完整流水：提问、每次工具调用、请求审批、完成、出错。

**暂停 / 取消** —— 时间线页底部。

> 「暂停」不是立刻冻结。Claude Code 没有这个能力。它实际是**在下一个工具调用前停住**，当前这一步会跑完。页面上有明确提示。

**发消息** ——「发消息」tab，选一个会话写一句话。

> 同样不是立刻送达。hooks 是单向的，唯一的注入点是「这一轮结束时」。所以你写的内容会在那个会话跑完当前这一轮后进入对话。适合「我看它方向不对，想让它换个做法」。

## 七、出问题了

### 手机上打不开

按顺序排查：

1. **手机和 Mac 在同一 Wi-Fi 吗**
2. **当前网络信任了吗** —— `npx clamicro networks`，没信任就 `npx clamicro trust`
3. **服务在跑吗** —— `npx clamicro status`
4. **地址方式对吗** —— 如果地址是 `xxx.local` 而你的路由器屏蔽了组播，就打不开。去「设置」→ 访问地址，页面会**从你手机实际测一次**并告诉你能不能解析；不能就切到 IP

### 没收到通知

- 首页顶部有没有「🔕 手机推送已关闭」的提示
- 「设置」里的「启用手机推送」开着吗、Bark key 填了吗
- 点「发一条测试通知」直接验证
- **注意**：会自动通过的操作**故意不推送**——10 秒就过了，推了你也来不及看

### Claude Code 卡住不动

多半是高危操作在等审批而通知没送达。

`npx clamicro status` 看有没有待审批，或者直接打开手机网页。

彻底停掉拦截：`npx clamicro uninstall`（只摘 Clamicro 加的东西）。

### 用量显示不对 / 一直是旧数据

页面上如果标着「⚠️ 这是 X 小时前的旧数据」，说明**没有会话在上报**。

原因：statusLine 是**会话启动时**读取配置的。你装 Clamicro 之前就开着的会话、或者装完之后改过安装路径，那些会话都不会上报。

解决：**新开一个 Claude Code 会话**。

### 换手机 / 清了浏览器数据

```bash
npx clamicro qr
```

重新扫一次。

## 八、设置项都是什么意思

| 设置 | 说明 |
|---|---|
| **Bark Key** | 手机推送凭证。不填也能用，只是离开电脑就收不到提醒 |
| **推送里显示命令全文** | 默认关。关闭时公网只看到「Bash 操作（高风险）」，命令原文只在局域网页面显示 |
| **macOS 通知** | 人在电脑边时由 Mac 自己出声，完全不联网 |
| **任务完成时提醒** + 最短时长 | `Stop` 每轮都触发，包括两秒的对话。默认只有超过 30 秒的任务才提醒 |
| **普通操作自动通过** + 等待时长 | 默认 10 秒。这段时间内你随时可以拒绝 |
| **高风险操作也自动通过** | ⚠️ 默认关。开了等于 `rm -rf` 在你没看手机时会自己放行——这正是审批功能要防的事 |
| **地址方式** | IP（一定能通）/ 主机名（换 IP 不用重扫码）。页面会从你手机实测后给建议 |

## 九、不想用了

```bash
npx clamicro uninstall
```

只摘掉自己加的东西，你原有的 hook 配置原样保留，改动前自动备份。

配置和历史留在 `~/.claude/clamicro/`，想彻底清干净就手动删掉这个目录。
