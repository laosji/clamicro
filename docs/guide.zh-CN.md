# Clamicro 使用教程

[← 回到 README](../README.zh-CN.md) · [English](./guide.md)

---

## 一、装

```bash
npx clamicro install
```

终端里会依次问你三件事：

**1. 要不要改 `~/.claude/settings.json`**

它会先把改动列出来给你看，再问要不要继续。你已有的 hook 配置一条不动，只追加；改之前自动备份。

**2. 要不要信任当前网络**

手机要连上服务，服务就得暴露到局域网。局域网内是明文传输，所以只在你信任的网络上开——家里、自己的热点可以，咖啡厅不行。

换到陌生网络时服务会自动缩回本机，等你再次确认。这是有意的保护，不是故障。

安装只问这些。**没有开机自启这一项**——服务跟着 Claude Code 走：`SessionStart` hook 会在你打开 Claude Code 时把它拉起来，关掉 Claude Code 它也就不需要在了。少一个常驻后台的东西。

（早期版本注册过 LaunchAgent。从那些版本升上来时会自动清掉，不用手动处理。）

最后会打印一个二维码。

## 二、第一次：走完一遍才算装好

用手机相机扫那个二维码，浏览器会打开首页。

登录一次就行——口令存成了 cookie，一年有效。以后手机上直接开那个地址。

**建议顺手做两件事：**

**加到主屏幕。** Safari 分享菜单 → 添加到主屏幕。之后它就是一个图标，没有地址栏，观感接近 App。

**跑一次验收。** 「设置」→ 最底下的「发一条测试审批」。这会造一条假的待审批，你在手机上批一次——**批准或拒绝都不会真的执行任何操作**。走完这一遍，说明整条链路是通的。

## 三、日常怎么用

### 场景一：你就在电脑边

什么都不用配。需要授权时：

- Mac 弹通知并响一声
- 终端状态栏出现 `⏳ 1 条待审批`
- 手机网页上也能看到

普通操作（`npm run build` 之类）**10 秒后自动通过**，你根本不用管。只有高风险操作会一直等你。

### 场景二：你离开了电脑

**没有任何东西会叫你。** 这是有意的——提醒只有 Mac 本地通知这一条，不联网。

所以：

- 你得自己想起来打开手机网页看
- 高风险操作会等到超时（默认 3 分钟）被**自动拒绝**，那一轮任务因此失败

第二条听起来严厉，但方向是对的：人不在的时候，`rm -rf` 就不该被放行。

> 早期版本有过远程推送（ntfy、Bark），删掉了。锁屏可达必须走 APNs，那必然经过第三方服务器，而换来的只是「离开电脑时能被叫一下」——这个工具的前提本来就是你人在附近。

### 场景三：你不在同一 Wi-Fi

默认用不了，这是设计如此。真需要的话装 Tailscale——服务会自动识别并绑上去，且不受网络信任限制。详见 [README 的安全章节](../README.zh-CN.md)。

## 四、审批页怎么读

这是唯一真正重要的一屏，从上到下：

```
┌──────────────────────────────────┐
│ my-project  …/dev/my-project 8:42│  ← 哪个会话，还剩多久
├──────────────────────────────────┤
│  [Bash] [读凭证] [改动文件]       │  ← 工具 + 影响面标签
│                                  │
│  ⚠️ 高风险操作                    │  ← 只有高危才出现
│  递归/强制删除 · 触及密钥文件     │
│                                  │
│  ⚠️ 描述与命令不符                │  ← 描述自称只读、命令却不是
│  描述称「查看构建产物」，          │
│  但命令会递归/强制删除            │
│                                  │
│  cat ~/[.ssh/id_rsa] > /tmp/x    │  ← 命令原文，主视觉。危险片段高亮
│  && [rm -rf] ~/proj/build        │                                  │
│  模型的描述                       │  ← 小字、灰色，明确标出是谁说的
│  查看构建产物                     │
│                                  │
│  ← 左滑拒绝 · 高风险，右滑需划得更远 → │
│  ━━━━━━━━━━━━━  8:42 后自动拒绝   │  ← 不操作会怎样
└──────────────────────────────────┘
```

**最该看的是命令原文**，它排在最上面且默认展开。

**「模型的描述」那一句排在命令下面、字更小**，这是有意的：那句话由 Claude Code 自己生成，是整条链路里唯一由被审查方写的文本。它可能与命令不符（无意或有意），所以不能占主视觉。真不符时页面会直接标出来——上图那个红框。

**危险片段会高亮**：命中风险规则的那几段（`rm -rf`、`.ssh/id_rsa`）在命令原文里被标出来，帮你先看最该看的地方。

但**高亮是提示，不是保证**：它靠的是对命令文本做模式匹配，而 `base64 -d | sh`、
变量间接引用、`curl … | sh`、或者危险动作藏在一个脚本文件里，这些都不会被标出来。
没有高亮不等于安全，只等于没命中规则。真正保护你的是你自己看那行命令。

**影响面标签**（只读 / 读凭证 / 改动文件 / 联网 / 提权）从命令里提取。看不出来时会老实标「影响面未知」，**不会假装只读**。

**底部那行倒计时**回答「我不管它会怎样」：

- 绿色「后自动通过」= 普通操作，10 秒后放行
- 灰色「后自动拒绝」= 高风险，等你决定，超时则拒绝

## 五、手势

| 动作 | 结果 |
|---|---|
| 左滑 | 拒绝 |
| 右滑 | 批准 |
| 高风险右滑 | 要划得更远（约屏幕 55%），而且不能"甩" |
| 列表里高风险右滑 | **完全划不动**，必须点进详情页 |

滑到某个位置时图章会「咬合」——放大、反白、震一下。**那一刻就是承诺点**，此时松手就会执行。没到那个状态松手会弹回来。

批准之后有 **3 秒撤销窗口**，全屏倒计时环，点「撤销」就取消。拒绝立即生效，不给撤销——误拒是安全方向，让 Claude 重试一次就行。

## 六、还能做什么

**看时间线** ——「会话」tab 点任意会话，能看到那个会话的完整流水：提问、每次工具调用、请求审批、完成、出错。

**暂停 / 取消** —— 时间线页底部。

> 「暂停」不是立刻冻结。Claude Code 没有这个能力。它实际是**在下一个工具调用前停住**，当前这一步会跑完。页面上有明确提示。

**发消息** ——「发消息」tab，选一个会话写一句话。

> 同样不是立刻送达。hooks 是单向的，唯一的注入点是「这一轮结束时」。所以你写的内容会在那个会话跑完当前这一轮后进入对话。适合「我看它方向不对，想让它换个做法」。

**在终端上批** —— 人就坐在 Mac 前时，不该还要去另一个房间拿手机：

```bash
npx clamicro pending          # 列出待审批，含「多少秒后会怎么处理」
npx clamicro approve          # 只有一条时直接批
npx clamicro approve 31454f39 # 指名批某一条
npx clamicro deny 31454f39
```

> **高风险操作必须写明 id 才能批准**，不能靠「反正只有一条」蒙过去。手机上高危右滑要划过 55% 且不给甩出快捷方式，终端这边得有等价的摩擦——两个入口松紧不一致的话，人会自然挑松的那个。批准前会把命令原文打出来，终端回滚记录里留一份。

## 七、出问题了

### 手机上打不开

按顺序排查：

1. **手机和 Mac 在同一 Wi-Fi 吗**
2. **当前网络信任了吗** —— `npx clamicro networks`，没信任就 `npx clamicro trust`
3. **服务在跑吗** —— `npx clamicro status`
4. **地址方式对吗** —— 如果地址是 `xxx.local` 而你的路由器屏蔽了组播，就打不开。去「设置」→ 访问地址，页面会**从你手机实际测一次**并告诉你能不能解析；不能就切到 IP

### 没收到通知

提醒只有 Mac 本地通知这一条，所以只有两种可能：

- 首页顶部有没有「🔕 提醒已全部关闭」的横幅——被关掉了
- 「设置」→ macOS 通知开着吗？点「发一条测试通知」直接验证
- macOS 的系统设置里，「通知」允许「脚本编辑器 / osascript」吗

**注意**：会自动通过的操作**故意不提醒**——10 秒就过了，提醒了你也来不及看。

### Claude Code 卡住不动

多半是高危操作在等审批而通知没送达。

`npx clamicro status` 看有没有待审批，或者直接打开手机网页。

彻底停掉拦截：`npx clamicro uninstall`（只摘 Clamicro 加的东西）。

### 用量显示不对 / 一直是旧数据

页面上如果标着「⚠️ 这是 X 小时前的旧数据」，说明**没有会话在上报**。

原因：statusLine 是**会话启动时**读取配置的。你装 Clamicro 之前就开着的会话、或者装完之后改过安装路径，那些会话都不会上报。

解决：**新开一个 Claude Code 会话**。

### 换了 Wi-Fi，或者 IP 变了

**新开一个 Claude Code 会话就行。** 服务会检测到绑的地址已经失效并自动重启到新地址，同时重新判断当前网络可不可信。

然后重新生成二维码（地址变了，旧链接失效）：

```bash
npx clamicro qr
```

### 换手机 / 清了浏览器数据

```bash
npx clamicro qr
```

重新扫一次。

## 八、设置项都是什么意思

| 设置 | 说明 |
|---|---|
| **macOS 通知** | 唯一的提醒通道，完全不联网。关掉就是彻底静默 |
| **通知样式** | 在 `config.json` 里改 `notify.style`：`notch`（默认，刘海位置的黑色胶囊）/ `banner`（系统标准通知）/ `both`。**取舍：刘海胶囊不进通知中心**，划过去就没了，人不在屏幕前等于没发生；想事后能翻到就用 `banner` 或 `both` |
| **任务完成时提醒** + 最短时长 | `Stop` 每轮都触发，包括两秒的对话。默认只有超过 30 秒的任务才提醒 |
| **普通操作自动通过** + 等待时长 | 默认 10 秒。这段时间内你随时可以拒绝 |
| **高风险操作也自动通过** | ⚠️ 默认关。开了等于 `rm -rf` 在你没看手机时会自己放行——这正是审批功能要防的事 |
| **地址方式** | IP（一定能通）/ 主机名（换 IP 不用重扫码）。页面会从你手机实测后给建议 |

## 九、不想用了

```bash
npx clamicro uninstall
```

只摘掉自己加的东西，你原有的 hook 配置原样保留，改动前自动备份。

配置和历史留在 `~/.claude/clamicro/`，想彻底清干净就手动删掉这个目录。
